# Contributing

boring-pond-common is part of The Boring Pond, maintained for its own use and shared.
Issues and small changes are welcome; answers come when there is time, and
fixes come with the next release. Security problems: SECURITY.md, not an
issue.

**Reporting a bug:** say which release, what you did, what happened, and the
relevant log lines. Remove tokens, keys, passwords and addresses you do not
want public.

**Changing something:**

- Small and one topic per pull request; for a new feature or a larger
  change, open an issue first and ask whether it fits.
- Run the check for what you touched: `python scripts/check.py`.
- Contributions come in under the project's licences (COPYING.md): code under
  the GNU AGPL 3.0 or later, documentation under CC BY-SA 4.0, the files
  COPYING.md marks public domain under CC0.

**AI:** all of this project — code, tests, docs — was written by AI; a person
decided what to build, tested it and ran it. AI-assisted contributions are
welcome on the same terms: say so, and the person sending the change has
tested it and stands behind it.
